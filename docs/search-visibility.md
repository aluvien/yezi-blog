# 搜索展示与收录

这些设置只改变搜索元信息和结构化数据。前台标题、正文、列表摘要、样式和交互继续使用原有内容与组件；不会自动重写文章，也不会根据标题猜测哪些文章应当隐藏。

## 后台使用

- 站点设置中的「网站搜索简介」用于首页和站点默认的搜索/分享介绍。留空依次使用站点副标题、代码默认介绍，不改前台副标题。
- 文章编辑器中的「文章搜索摘要」最多 300 个字符。留空时沿用正文前 120 字的自动摘要。搜索引擎可以自行选择最终显示的摘要。
- 「允许搜索引擎收录」默认开启。关闭后该文章返回 `noindex, follow` 并退出 sitemap，但依然公开可读；它不是隐私或访问权限开关。已有搜索结果需要等待搜索引擎重新抓取才能更新。
- 浏览器草稿保存上述文章设置；旧草稿不含这些字段时保留该文章原有设置。

## 自动输出

- 公开页面输出 WebSite 和 Person；文章页另输出 BlogPosting。使用当前后台配置的域名、作者、文章标题、封面和真实发布时间/更新时间，不输出邮箱、令牌等私有设置。
- JSON-LD 在服务器输出，转义 HTML 结束标签并使用现有 CSP nonce。
- `/posts?page=2` 等有效分页使用自身 canonical；第一页统一为 `/posts`。超出实际页数的空列表与站内搜索页设置 `noindex, follow`，后台与登录页设置 `noindex, nofollow`。
- sitemap 包含 `/posts` 和允许收录的已发布文章，不包含草稿、后台或搜索结果。
- 不改变公开爬虫访问规则、不新增絮语详情地址、不添加 llms.txt。文章与絮语的可见布局保持原样。

## 兼容与部署

- 数据库迁移 20 添加 `posts.seo_description`（默认空字符串）与 `posts.seo_noindex`（默认 0），原文、状态、日期及缩略图数据保持不变。
- 管理 API 文章详情新增 `seoDescription: string` 与 `seoNoindex: boolean`，POST/PATCH 接受这两个可选字段。旧版 App 或直接调用 DAO 时省略字段会保留既有设置，显式空字符串/false 恢复默认。
- 采用既有原目录更新流程及部署前备份。已有数据库的构建仍遵守只读构建规则；实际迁移由既有部署流程处理。回滚到不支持迁移 20 的版本时，应按部署回滚机制同时恢复匹配的数据库备份。
- 不自动部署、修改域名解析或开通站长平台。部署后可向 Google Search Console 和 Bing Webmaster Tools 提交 `/sitemap.xml`，检查规范地址和实际收录变化。
